About Safira

Safira is a programming language in plain words, made for people who have never programmed. It works in English, Portuguese, Spanish, Chinese and Japanese, and you can even mix them in the same program. It runs right in the browser, on a computer or on a phone: nothing to install, no account and no ads.

Who it is for

  • Anyone writing a first line of code, at any age.
  • Teachers who want a first class on logic without installing anything.
  • People who do not read English: Safira also speaks Portuguese, Spanish, Chinese and Japanese.

A short program

Many ways to show a text, the same line, two languages mixed, a loop and a condition:

# Many ways to say the same thing, with color.
name receives "Ana"
age is worth 12
show "Hello, " + name + "!" in color blue
display on the screen "You are " + age + " years old."
write on the screen "All of these show a text." in color green

# On the same line, and even in Portuguese.
show on this line "Safira "
print "speaks "
mostre "Portuguese too."

repeat 3 times {
    show on this line "⭐" in color yellow
}
show ""

if age is greater than or equal to 10 then {
    show "You can code already! 🎉" in color pink
} else {
    show "You can too, with help! 🎉"
}

Questions

Is it free?
Yes. Safira is open source, under the MIT license.
Are there ads?
No. There are no ads and nothing tracks what you do.
Can I change Safira or make my own version?
Yes. The code is on GitHub under the MIT license: you can copy it, change it and publish your own version, as long as you keep the license notice.
Do I need to install anything or create an account?
No. Open the site in a current browser. There are no accounts.
Does it work on a phone?
Yes. On a phone the IDE splits into Code, Output and Variables panels.
Does my code go to a server?
No. Programs run in the browser and projects stay in this browser. Export a project as a .zip to keep a copy or move it to another device.
Can I mix languages in the same program?
Yes. Every language is active all the time, even on the same line.
Can I make a game?
Yes. Programs can read the keyboard. Open Dinosaur or Mini RPG in the Examples menu to see how.

History

Safira was born in August 2019, early in the career of Gabriel Gregorio, with one goal: letting people who had never programmed write their first program with the words they already use every day. The first version was a language and an IDE written in Python, installed on the computer, in Portuguese, English and Spanish.

Version 0.38, from May 2021, was the last one in Python. In 2026 Safira was rewritten from scratch for the web, in TypeScript: version 1.0.0 took the IDE to the browser and to phones, added Chinese and Japanese, projects with folders, breakpoints, a variables inspector and the lessons with the cat. Now the first line of code is one link away.

Before the Python code left the project, the output of its programs was recorded, and that recording became a test that still runs: scripts written for the Python version run the same on the web.
