# ユーザーに質問する

使っている人と話せると、プログラムはもっと楽しくなります。

## 文字を読み取る

`入力` で、プログラムは止まって待ちます。出力パネルの入力欄に書いて、Enter を押しましょう。

```safira
表示 "お名前は何ですか?"
名前 = 入力

表示 "こんにちは、" + 名前
```

## 数を読み取る

入力されたもので計算したいときは、数を頼みます。

```safira
表示 "数を入力してください:"
数 = 数字入力

倍 = 数 * 2
表示 "2倍は " + 倍
```

## チャレンジ: 3倍

数を1つ聞いて、その3倍を表示しましょう。

```safira
# ユーザーに数を聞いてください。

# その数の3倍を表示してください。

```

```solution
表示 "数を入力してください:"
数 = 数字入力

表示 数 * 3
```
