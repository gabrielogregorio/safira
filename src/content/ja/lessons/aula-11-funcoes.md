# 関数

関数は、名前がついたコードのかたまりです。1回書けば、何回でも使えます。

## 作って呼ぶ

関数を作っただけでは何も動きません。名前を呼んだときに動きます。

```safira
関数 こんにちは {
    表示 "こんにちは!"
    表示 "お元気ですか?"
}

こんにちは()
こんにちは()
```

## 値を渡す

関数は、値を受け取ってそれを使えます。

```safira
関数 あいさつ(名前) {
    表示 "こんにちは、" + 名前
}

あいさつ("Ana")
あいさつ("Bia")
```

## 結果を返す

`返す` は、呼んだ場所に結果を渡します。

```safira
関数 倍(数) {
    返す 数 * 2
}

表示 倍(4)
```

## チャレンジ: 足し算

2つの数を受け取って、その合計を返す `足し算` という関数を作りましょう。そのあと `足し算(2, 3)` を表示します。

```safira
# ここで関数を作ってください。

# ここで 足し算(2, 3) を表示してください。

```

```solution
関数 足し算(a, b) {
    返す a + b
}

表示 足し算(2, 3)
```
