# 条件

`もし` を使うと、プログラムが何をするか選べます。

## もし

`{` と `}` の間のブロックは、条件が正しいときだけ動きます。20を10に変えて、もう一度実行してみましょう。

```safira
年齢 = 20

もし 年齢 大なり 17 なら {
    表示 "運転できます"
}
```

## そうでなければ

`そうでなければ` は反対の道です。条件が正しくないときに動きます。

```safira
点数 = 4

もし 点数 以上 6 なら {
    表示 "合格"
} そうでなければ {
    表示 "不合格"
}
```

## 比べる

`等しい`、`等しくない`、`大なり`、`小なり` が使えます。

```safira
パスワード = "safira"

もし パスワード 等しい "safira" なら {
    表示 "入ってください"
}
```

## チャレンジ: 偶数か奇数か

数を1つ聞きます。2で割った余りが0なら `偶数`、そうでなければ `奇数` と表示しましょう。

`%` は割り算の余りです。`7 % 2` は1になります。

```safira
表示 "数を入力してください:"
数 = 数字入力

# ここに もし を書いてください。

```

```solution
表示 "数を入力してください:"
数 = 数字入力

もし 数 % 2 等しい 0 なら {
    表示 "偶数"
} そうでなければ {
    表示 "奇数"
}
```
