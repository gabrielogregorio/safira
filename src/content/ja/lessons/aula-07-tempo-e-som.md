# 時間と音

プログラムは、待ったり音を鳴らしたりもできます。

## 待つ

`待つ` は、次のコマンドの前に少し止まります。

```safira
表示 "よーい..."
待つ 1 秒
表示 "スタート!"
```

## 音を鳴らす

`鳴らす` は音を鳴らします。`C`、`D`、`E` や `ド`、`レ`、`ミ` が使えます。

```safira
鳴らす ド 長さ 0.5 秒
鳴らす ミ 長さ 0.5 秒
鳴らす ソ 長さ 1 秒
```

## チャレンジ: カウントダウン

3、2、1と、数の間に待ち時間を入れて表示し、最後に `発射!` と表示しましょう。

```safira
# 3を表示して、待って、2を表示して、待って、1を表示して、待ちます。

# 最後に 発射! と表示してください。

```

```solution
表示 3
待つ 1 秒
表示 2
待つ 1 秒
表示 1
待つ 1 秒
表示 "発射!"
```
