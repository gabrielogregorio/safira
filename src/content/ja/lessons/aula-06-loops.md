# くり返し

コンピューターはくり返しに疲れません。何回かだけ伝えましょう。

## 繰り返す

`繰り返す` は、頼んだ回数だけブロックを動かします。

```safira
繰り返す 3 回 {
    表示 "こんにちは!"
}
```

## 数える

`数える` が数えてくれて、変数は1回ごとに変わります。

```safira
数える 数 を 1 から 5 {
    表示 数
}
```

## 条件ループ

`条件ループ` は、条件が正しくなくなるまでくり返します。終わるには 0 を入力します。

```safira
数 = 1

条件ループ 数 等しくない 0 {
    表示 "終わるには 0 を入力してください:"
    数 = 数字入力
}

表示 "おしまい!"
```

## チャレンジ: 2のだん

2のだんを10まで表示しましょう。2、4、6、と続きます。くり返しを使います。

```safira
# 1から10まで数えて、その数の2倍を表示してください。

```

```solution
数える 数 を 1 から 10 {
    表示 数 * 2
}
```
