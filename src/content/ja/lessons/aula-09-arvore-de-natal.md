# 光るツリー

## 光るツリー

ツリーはもうここにあります。光らせるには、2本目のツリーで飾りを ⚫ に変えます。

ツリーを 3 回点滅させましょう:`繰り返す`、`画面消去`、`待つ 1 秒` を使い、点いたツリーと消えたツリーを表示します。

```safira
表示 "    ⭐"
表示 "   🎄🎄"
表示 "  🎄🔴🎄"
表示 " 🎄🟡🎄🔵"
表示 "    🟫"
表示 "🎅 メリークリスマス!"
```

```solution
繰り返す 3 回 {
    画面消去
    表示 "    ⭐"
    表示 "   🎄🎄"
    表示 "  🎄🔴🎄"
    表示 " 🎄🟡🎄🔵"
    表示 "    🟫"
    表示 "🎅 メリークリスマス!"
    待つ 1 秒

    画面消去
    表示 "    ⭐"
    表示 "   🎄🎄"
    表示 "  🎄⚫🎄"
    表示 " 🎄⚫🎄⚫"
    表示 "    🟫"
    表示 "🎅 メリークリスマス!"
    待つ 1 秒
}
```
