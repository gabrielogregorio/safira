# ランダムに選ぶ

ゲームには運が必要です。コンピューターは数をランダムに選べます。

## サイコロをふる

何回か実行してみましょう。数が変わります。

```safira
さいころ = 乱数 1 から 6

表示 "出た数は " + さいころ
```

## 運と条件

ランダムな数と `もし` を組み合わせると、プログラムが自分で決めます。

```safira
コイン = 乱数 1 から 2

もし コイン 等しい 1 なら {
    表示 "表"
} そうでなければ {
    表示 "裏"
}
```

## チャレンジ: 当てよう

1から3の数をランダムに選んで、`答え` に入れます。数を1つ聞いて、同じなら `当たり`、違うなら `はずれ` と表示しましょう。

```safira
# ここで 答え を選んでください。

表示 "1から3の数を当ててください:"
予想 = 数字入力

# ここで 予想 と 答え を比べてください。

```

```solution
答え = 乱数 1 から 3

表示 "1から3の数を当ててください:"
予想 = 数字入力

もし 予想 等しい 答え なら {
    表示 "当たり"
} そうでなければ {
    表示 "はずれ"
}
```
