# 信号機

## 信号機

`画面消去` で画面を消し、`繰り返す 2 回 {` で繰り返します。

2 回繰り返す信号機を作りましょう:`止まれ` を 4 秒、`進め` を 4 秒、`注意` を 2 秒表示し、その間に画面を消します。

```safira
# ここに書きましょう。
```

```solution
繰り返す 2 回 {
    画面消去
    表示 "🔴 止まれ"
    待つ 4 秒

    画面消去
    表示 "🟢 進め"
    待つ 4 秒

    画面消去
    表示 "🟠 注意"
    待つ 2 秒
}
```
