# 信号機

## 信号機

```safira
# 全部を 2 回繰り返します。
# 画面を消して、文字を表示して、待ちます。
繰り返す 2 回 {
    画面消去
    表示 "こんにちは"
    待つ 1 秒

    画面消去
    表示 "さようなら"
    待つ 1 秒
}
```

## チャレンジ: 信号機

```safira
# チャレンジ: 2 回繰り返す信号機を作りましょう。
# 止まれ を 4 秒、進め を 4 秒、注意 を 2
# 秒表示します。
# 間に画面を消します。

```

```solution
繰り返す 2 回 {
    画面消去
    表示 "🔴 止まれ"
    待つ 4 秒

    画面消去
    表示 "🟢 進め"
    待つ 4 秒

    画面消去
    表示 "🟠 注意"
    待つ 2 秒
}
```
