## 当ててみて

`乱数 1 から 3` で数字を選び、`もし a 等しい b なら {` で比べます。続きは `} そうでなければ {` です。

数字を `秘密` に入れ、数字を聞いて、同じなら `当たり`、違えば `はずれ` と表示しましょう。

```safira

```

```solution
秘密 = 乱数 1 から 3
予想 = 数字入力

もし 予想 等しい 秘密 なら {
    表示 "当たり"
} そうでなければ {
    表示 "はずれ"
}
```
