# リスト

リストは、たくさんの値を1つの変数に入れておけます。

## リストを作る

位置は1から始まります。

```safira
リスト 果物 は "ぶどう", "りんご", "マンゴー"

表示 果物
表示 リスト 果物 位置 1
表示 リストの長さ 果物
```

## 追加と削除

`追加` で最後に追加し、`削除` で取り除きます。

```safira
リスト 果物 は "ぶどう", "りんご"

追加 "マンゴー" リスト末尾 果物
削除 "ぶどう" リストから 果物

表示 果物
```

## すべての項目を見る

`順番に` で、1つずつ順番に見ていきます。

```safira
リスト 果物 は "ぶどう", "りんご", "マンゴー"

順番に 果物 取り出す 果 {
    表示 果 + "が好きです"
}
```

## チャレンジ: 買い物リスト

`買い物` というリストに `お米` と `豆` を入れます。最後に `牛乳` を追加して、項目を1行ずつ表示しましょう。

```safira
# ここでリストを作ってください。

# ここで牛乳を追加してください。

# ここで項目を1つずつ表示してください。

```

```solution
リスト 買い物 は "お米", "豆"

追加 "牛乳" リスト末尾 買い物

順番に 買い物 取り出す 品 {
    表示 品
}
```
