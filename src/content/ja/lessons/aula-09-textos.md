# 文字をあつかう

文字の形を変えたり、1文字ずつ見たりできます。

## 大文字と小文字

文字は、すべて大文字、すべて小文字、最初だけ大文字にできます。

```safira
名前 = "ana maria"

表示 名前 大文字
表示 名前 小文字
表示 名前 先頭大文字
```

## 1文字ずつ

`順番に` は、1文字ずつ順番に見ていきます。

```safira
単語 = "Sun"

順番に 単語 取り出す 文字 {
    表示 文字
}
```

## チャレンジ: さけぶ

文字を1つ聞いて、その文字をすべて大文字で表示しましょう。

```safira
表示 "英語の単語を入力してください:"
単語 = 入力

# ここで word を大文字で表示してください。

```

```solution
表示 "英語の単語を入力してください:"
単語 = 入力

表示 単語 大文字
```
