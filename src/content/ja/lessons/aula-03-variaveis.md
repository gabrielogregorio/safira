# 変数

変数は、名前がついた小さな箱です。あとで使うために値を入れておけます。

## 値をしまう

`=` で箱に値を入れます。あとは名前を書くだけで使えます。

```safira
名前 = "Ana"
年齢 = 20

表示 名前
表示 年齢
```

## 変数を見る

実行したあと、変数パネルを見てみましょう。変数の名前、値、種類が表示されます。

1歩ずつ見たいときは、実行メニューを開いて「1行ずつ実行」を選びます。

```safira
点 = 10
点 = 点 + 5

表示 点
```

## 文字と変数をつなぐ

`+` で、文字と変数をつないで1つの文にできます。

```safira
名前 = "Ana"
年齢 = 20

表示 "わたしの名前は" + 名前 + "です"
表示 "年は" + 年齢 + "歳です"
```

## チャレンジ: あなたの町

`都市` という変数に `Lima` を入れて、文字と変数をつなげて `Limaに住んでいます` と表示しましょう。

```safira
# ここで変数を作ってください。

# ここで文を表示してください。

```

```solution
都市 = "Lima"
表示 都市 + "に住んでいます"
```
