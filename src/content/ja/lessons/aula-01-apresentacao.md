# サフィラへようこそ

サフィラは、話すように書けるプログラミング言語です。

## はじめてのプログラム

プログラムとは、コンピューターへの命令のリストです。これは命令が1つだけで、文字を画面に表示します。

サフィラのコマンドは、ここでは英語の単語で書きます。たとえば `print` は「表示する」という意味です。説明や文字の部分は日本語で書けます。

▶ 実行を押して、横に出る結果を見てみましょう。

```safira
print "こんにちは、世界!"
```

## 1つずつ順番に

サフィラは、上から下へ1行ずつ読みます。`print` を書くたびに、新しい行に表示されます。

```safira
print "1つめ"
print "2つめ"
print "3つめ"
```

## コメント

`#` で始まる行はコメントです。コードを読む人へのメモで、コンピューターは無視します。

```safira
# この行は画面に表示されません。
print "これは表示されます!"
```
