# サフィラへようこそ

サフィラは、話すように書けるプログラミング言語です。

## はじめてのプログラム

プログラムとは、コンピューターへの命令のリストです。これは命令が1つだけで、文字を画面に表示します。

サフィラのコマンドは日本語で書きます。たとえば `表示` は画面に出すコマンドです。コマンドや名前は、スペースで区切ります。

▶ 実行を押して、横に出る結果を見てみましょう。

```safira
表示 "こんにちは、世界!"
```

## 1つずつ順番に

サフィラは、上から下へ1行ずつ読みます。`表示` を書くたびに、新しい行に表示されます。

```safira
表示 "1つめ"
表示 "2つめ"
表示 "3つめ"
```

## コメント

`#` で始まる行はコメントです。コードを読む人へのメモで、コンピューターは無視します。

```safira
# この行は画面に表示されません。
表示 "これは表示されます!"
```

## チャレンジ: あいさつ

```safira

```
