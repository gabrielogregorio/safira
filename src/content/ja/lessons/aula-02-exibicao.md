# 画面に表示する

`表示` は文字を出すだけではありません。計算をしたり、色をつけたりもできます。

## 文字と数

文字は引用符で囲みます。数は囲みません。計算はコンピューターがしてくれます。

```safira
表示 "2たす2は:"
表示 2 + 2
表示 10 * 3
```

## 同じ行に表示する

`続けて表示` を使うと、次の表示が同じ行に続きます。

```safira
続けて表示 "おは"
続けて表示 "よう!"
```

## 色

文字のあとに `色` を付けます。色の名前や、`#ff1122` のようなコードが使えます。

```safira
表示 "青" 色 青
表示 "紫" 色 紫
表示 "赤" 色 #ff1122
```

## チャレンジ: 計算

`25 * 4` の結果を表示しましょう。答えを書かずに、コンピューターに計算させます。

```safira
# ここに 25 * 4 の結果を表示してください。

```

```solution
表示 25 * 4
```
