# 红绿灯

## 红绿灯

`清屏` 清除显示的内容,`重复 2 次 {` 用来重复。

```safira
重复 2 次 {
    清屏
    显示 "你好"
    等待 1 秒

    清屏
    显示 "再见"
    等待 1 秒
}
```

## 挑战:红绿灯

做一个重复 2 次的红绿灯:显示 `停` 4 秒,显示 `走` 4 秒,显示 `注意` 2 秒,中间清屏。

```safira
# 在这里写。
```

```solution
重复 2 次 {
    清屏
    显示 "🔴 停"
    等待 4 秒

    清屏
    显示 "🟢 走"
    等待 4 秒

    清屏
    显示 "🟠 注意"
    等待 2 秒
}
```
