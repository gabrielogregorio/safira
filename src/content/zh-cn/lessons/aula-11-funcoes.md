# 函数

函数是一段有名字的代码。你写一次，就可以用很多次。

## 创建和调用

创建函数不会运行任何东西。只有当你调用它的名字时，它才会运行。

```safira
函数 你好 {
    显示 "你好！"
    显示 "还好吗？"
}

你好()
你好()
```

## 传入一个值

函数可以接收值，并用这些值来工作。

```safira
函数 问候(名字) {
    显示 "你好，" + 名字
}

问候("小安")
问候("小美")
```

## 返回结果

`返回` 把一个结果交给调用它的地方。

```safira
函数 两倍(数值) {
    返回 数值 * 2
}

显示 两倍(4)
```

## 挑战：求和

创建函数 `求和`，它接收两个数字，并返回它们的和。然后显示 `求和(2, 3)`。

```safira
# 在这里创建函数。

# 在这里显示 求和(2, 3)。

```

```solution
函数 求和(甲, 乙) {
    返回 甲 + 乙
}

显示 求和(2, 3)
```
