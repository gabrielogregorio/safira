# 玩转文字

你可以改变文字的写法，也可以一个字母一个字母地看。

## 大写和小写

一段文字可以全部大写、全部小写，或者只有第一个字母大写。

```safira
名字 = "ana maria"

显示 名字 转大写
显示 名字 转小写
显示 名字 首字母大写
```

## 一个字母一个字母

`遍历` 会一个一个地走过每个字母。

```safira
单词 = "Sol"

遍历 单词 放入 字母 {
    显示 字母
}
```

