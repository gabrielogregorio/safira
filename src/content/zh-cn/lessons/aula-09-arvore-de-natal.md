# 闪烁的圣诞树

## 闪烁的圣诞树

`清屏` 和 `等待` 可以让任何东西闪烁。

```safira
重复 2 次 {
    清屏
    显示 "⭐"
    等待 1 秒

    清屏
    显示 "🌟"
    等待 1 秒
}
```

## 挑战:闪烁的圣诞树

让树闪烁 3 次:用 `重复`、`清屏` 和 `等待 1 秒`,先显示亮的树,再显示暗的树。

```safira
显示 "    ⭐"
显示 "   🎄🎄"
显示 "  🎄🔴🎄"
显示 " 🎄🟡🎄🔵"
显示 "    🟫"
显示 "🎅 圣诞快乐!"
```

```solution
重复 3 次 {
    清屏
    显示 "    ⭐"
    显示 "   🎄🎄"
    显示 "  🎄🔴🎄"
    显示 " 🎄🟡🎄🔵"
    显示 "    🟫"
    显示 "🎅 圣诞快乐!"
    等待 1 秒

    清屏
    显示 "    ⭐"
    显示 "   🎄🎄"
    显示 "  🎄⚫🎄"
    显示 " 🎄⚫🎄⚫"
    显示 "    🟫"
    显示 "🎅 圣诞快乐!"
    等待 1 秒
}
```
