## 闪烁的圣诞树

```safira
# 清屏加等待,什么都能闪烁。

    清屏

}
```

## 挑战:闪烁的圣诞树

```safira
# 挑战:让树闪烁 3 次:用 重复、清屏 和 等待 1
# 秒,先显示亮的树,再显示暗的树。

显示 "    ⭐"
显示 "   🎄🎄"
显示 "  🎄🔴🎄"
显示 " 🎄🟡🎄🔵"
显示 "    🟫"

```

```solution
重复 3 次 {
    清屏
    显示 "    ⭐"
    显示 "   🎄🎄"
    显示 "  🎄🔴🎄"
    显示 " 🎄🟡🎄🔵"
    显示 "    🟫"
    显示 "🎅 圣诞快乐!"
    等待 1 秒

    清屏
    显示 "    ⭐"
    显示 "   🎄🎄"
    显示 "  🎄⚫🎄"
    显示 " 🎄⚫🎄⚫"
    显示 "    🟫"
    显示 "🎅 圣诞快乐!"
    等待 1 秒
}
```
