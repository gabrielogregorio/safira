# 重复

电脑重复做事从不觉得累。你只要告诉它做几次。

## 重复

`重复` 会把代码块运行你指定的次数。

```safira
重复 3 次 {
    显示 "你好！"
}
```

## 数数

`对于` 帮你数数，变量每一圈都会变化。

```safira
对于 数值 从 1 到 5 {
    显示 数值
}
```

## 当

`当` 会一直重复，直到条件变为假。输入 0 就退出。

```safira
数值 = 1

当 数值 不等于 0 {
    显示 "输入 0 退出："
    数值 = 输入数字
}

显示 "结束！"
```

## 挑战：2 的乘法表

显示 2 的乘法表，一直到 10：2、4、6，依此类推。请使用重复。

```safira
# 从 1 数到 10，显示这个数字乘以 2。

```

```solution
对于 数值 从 1 到 10 {
    显示 数值 * 2
}
```
