# 时间和声音

程序还可以等待，也可以演奏音符。

## 等待

`等待` 会在下一条命令之前暂停一下。

```safira
显示 "准备……"
等待 1 秒
显示 "开始！"
```

## 演奏一个音符

`播放` 演奏一个音符。可以用 `C`、`D`、`E`，也可以用 `Do`、`Re`、`Mi`。

```safira
播放 Do 持续 0.5 秒
播放 Mi 持续 0.5 秒
播放 Sol 持续 1 秒
```

## 挑战：倒计时

显示 3、2、1，数字之间要等待，最后显示 `开火！`。

```safira
# 显示 3，等待，显示 2，等待，显示 1，等待。

# 最后，显示 开火！

```

```solution
显示 3
等待 1 秒
显示 2
等待 1 秒
显示 1
等待 1 秒
显示 "开火！"
```
