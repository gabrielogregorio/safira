# 欢迎来到 Safira

Safira 是一种编程语言，你写代码就像说话一样。

## 你的第一个程序

程序就是一串给电脑的命令。这个程序只有一条命令：在屏幕上显示一段文字。

注意：在这里，Safira 的命令是用中文写的，比如 `显示`，文字和注释也用中文写。

点击 ▶ 运行，在旁边看结果。

```safira
显示 "你好，世界！"
```

## 一条接一条

Safira 从上往下读，一次读一行。每个 `显示` 都会另起一行。

```safira
显示 "第一"
显示 "第二"
显示 "第三"
```

## 注释

以 `#` 开头的行是注释。它是写给读代码的人看的，电脑会忽略它。

```safira
# 这一行不会显示在屏幕上。
显示 "这一行会显示！"
```
