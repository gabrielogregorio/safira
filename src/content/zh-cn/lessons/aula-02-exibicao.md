# 显示在屏幕上

`显示` 不只是显示文字，它还能做计算、用颜色。

## 文字和数字

文字要放在引号里。数字不加引号，电脑会替你算。

```safira
显示 "二加二等于："
显示 2 + 2
显示 10 * 3
```

## 全部写在同一行

用 `同行显示`，下一个内容会接着同一行写。

```safira
同行显示 "早"
同行显示 "上好！"
```

## 颜色

在文字后面加上 `颜色`。可以用颜色名，也可以用像 `#ff1122` 这样的代码。

```safira
显示 "蓝色" 颜色 蓝色
显示 "紫色" 颜色 紫色
显示 "红色" 颜色 #ff1122
```

## 挑战：算一算

显示 `25 * 4` 的结果。让电脑来算，不要自己写出结果。

```safira
# 在这里显示 25 * 4 的结果。

```

```solution
显示 25 * 4
```
