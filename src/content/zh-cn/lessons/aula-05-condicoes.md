# 条件

用 `如果`，程序就能选择做什么。

## 如果

只有当条件为真时，`{` 和 `}` 之间的代码才会运行。把 20 改成 10，再运行一次。

```safira
年龄 = 20

如果 年龄 大于 17 那么 {
    显示 "可以开车"
}
```

## 否则

`否则` 是相反的路：条件为假时运行。

```safira
成绩 = 4

如果 成绩 大于等于 6 那么 {
    显示 "及格"
} 否则 {
    显示 "不及格"
}
```

## 比较

你可以用 `等于`、`不等于`、`大于` 和 `小于`。

```safira
密码 = "safira"

如果 密码 等于 "safira" 那么 {
    显示 "请进"
}
```

## 挑战：偶数还是奇数

请用户输入一个数字。如果它除以 2 的余数是 0，就显示 `偶数`。否则显示 `奇数`。

符号 `%` 得到除法的余数：`7 % 2` 是 1。

```safira
显示 "请输入一个数字："
数值 = 输入数字

# 在这里写 如果。

```

```solution
显示 "请输入一个数字："
数值 = 输入数字

如果 数值 % 2 等于 0 那么 {
    显示 "偶数"
} 否则 {
    显示 "奇数"
}
```
