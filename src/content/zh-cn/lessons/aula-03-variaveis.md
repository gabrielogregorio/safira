# 变量

变量就像一个有名字的小盒子。它保存一个值，留着以后使用。

## 保存一个值

`=` 把值放进小盒子里。之后只要用它的名字就行了。

```safira
名字 = "小安"
年龄 = 20

显示 名字
显示 年龄
```

## 看看变量

运行之后，看一下“变量”面板：它会显示每个变量的名字、值和类型。

想一步一步地看吗？打开“运行”菜单，选择“逐行运行”。

```safira
分数 = 10
分数 = 分数 + 5

显示 分数
```

## 把文字和变量连起来

`+` 可以把文字和变量连成一句话。

```safira
名字 = "小安"
年龄 = 20

显示 "我的名字是" + 名字
显示 "我今年" + 年龄 + "岁"
```
