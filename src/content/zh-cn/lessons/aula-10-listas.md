# 列表

列表可以在一个变量里装很多个值。

## 创建列表

位置从 1 开始数。

```safira
列表 水果 包含 "葡萄", "苹果", "芒果"

显示 水果
显示 列表 水果 位置 1
显示 列表长度 水果
```

## 添加和删除

用 `添加` 在末尾加一个项目，用 `移除` 删掉一个项目。

```safira
列表 水果 包含 "葡萄", "苹果"

添加 "芒果" 到列表末尾 水果
移除 "葡萄" 从列表 水果

显示 水果
```

## 走过所有项目

`遍历` 会一个一个地走过列表里的每个项目。

```safira
列表 水果 包含 "葡萄", "苹果", "芒果"

遍历 水果 放入 水果项 {
    显示 "我喜欢" + 水果项
}
```

## 挑战：购物清单

创建列表 `清单`，里面有 `米饭` 和 `豆子`。在末尾添加 `牛奶`，然后每个项目显示一行。

```safira
# 在这里创建列表。

# 在这里添加牛奶。

# 在这里显示每个项目。

```

```solution
列表 清单 包含 "米饭", "豆子"

添加 "牛奶" 到列表末尾 清单

遍历 清单 放入 项 {
    显示 项
}
```
