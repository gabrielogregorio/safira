# 随机

游戏需要运气，电脑会随机抽数字。

## 掷骰子

多运行几次：数字会变。

```safira
骰子 = 随机数 1 到 6

显示 "掷出了 " + 骰子
```

## 运气和条件

把随机数和 `如果` 结合起来，程序就能自己做决定。

```safira
硬币 = 随机数 1 到 2

如果 硬币 等于 1 那么 {
    显示 "正面"
} 否则 {
    显示 "反面"
}
```

## 挑战：猜一猜

随机抽一个 1 到 3 之间的数字，保存在 `答案` 里。请用户输入一个数字。如果相等，就显示 `猜对了`。否则显示 `猜错了`。

```safira
# 在这里随机抽出 secret。

显示 "猜一个 1 到 3 的数字："
猜测 = 输入数字

# 在这里比较 guess 和 secret。

```

```solution
答案 = 随机数 1 到 3

显示 "猜一个 1 到 3 的数字："
猜测 = 输入数字

如果 猜测 等于 答案 那么 {
    显示 "猜对了"
} 否则 {
    显示 "猜错了"
}
```
