# 询问用户

程序会和使用它的人聊天，就更有意思了。

## 读取文字

`输入` 会让程序停下来等待。在输出面板的输入框里打字，然后按回车。

```safira
显示 "你叫什么名字？"
名字 = 输入

显示 "你好，" + 名字
```

## 读取数字

想用输入的内容做计算，就要请用户输入数字。

```safira
显示 "请输入一个数字："
数值 = 输入数字

两倍 = 数值 * 2
显示 "它的两倍是 " + 两倍
```

## 挑战：三倍

请用户输入一个数字，然后显示它的三倍。

```safira
# 请用户输入一个数字。

# 显示这个数字乘以 3。

```

```solution
显示 "请输入一个数字："
```
