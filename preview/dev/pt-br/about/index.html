Sobre a Safira

A Safira é uma linguagem de programação em português, feita para quem nunca programou. Ela também existe em inglês, espanhol, chinês e japonês, e dá para misturar os idiomas no mesmo programa. Roda direto no navegador, no computador ou no celular: sem instalar nada, sem conta e sem anúncios.

Para quem é

  • Quem vai escrever a primeira linha de código, em qualquer idade.
  • Professores que querem uma primeira aula de lógica sem instalar nada.
  • Quem não lê inglês: a Safira fala português, e também inglês, espanhol, chinês e japonês.

Um programa curto

Várias formas de mostrar um texto, a mesma linha, dois idiomas misturados, uma repetição e uma condição:

# Várias formas de dizer a mesma coisa, com cor.
nome recebe "Ana"
idade vale 12
mostre "Olá, " + nome + "!" na cor azul
exiba "Você tem " + idade + " anos."
imprima na tela "Tudo isso mostra um texto." na cor verde

# Na mesma linha, e até em inglês.
mostre nessa linha "A Safira "
print "fala "
show "inglês também."

repita 3 vezes {
    mostre nessa linha "⭐" na cor amarelo
}
mostre ""

se idade for maior ou igual a 10 então {
    mostre "Já dá para programar! 🎉" na cor rosa
} senão {
    mostre "Dá também, com ajuda! 🎉"
}

O que ele mostra

Olá, Ana!
Você tem 12 anos.
Tudo isso mostra um texto.
A Safira fala inglês também.
⭐⭐⭐
Já dá para programar! 🎉

Dúvidas

É grátis?
Sim. A Safira é de código aberto, com licença MIT.
Tem anúncio?
Não. Não tem anúncio e nada rastreia o que você faz.
Posso modificar a Safira ou criar a minha versão?
Pode. O código está no GitHub com licença MIT: você pode copiar, modificar e publicar a sua versão, desde que mantenha o aviso da licença.
Preciso instalar alguma coisa ou criar conta?
Não. Abra o site num navegador atual. Não existe conta.
Funciona no celular?
Sim. No celular a IDE se divide nos painéis Código, Saída e Variáveis.
Meu código vai para algum servidor?
Não. Os programas rodam no navegador e os projetos ficam neste navegador. Exporte o projeto em .zip para guardar uma cópia ou levar para outro aparelho.
Posso misturar idiomas no mesmo programa?
Pode. Todos os idiomas valem o tempo todo, até na mesma linha.
Dá para fazer um jogo?
Dá. Os programas leem o teclado. Abra Dinossauro ou Mini RPG no menu Exemplos para ver como.

História

A Safira nasceu em agosto de 2019, no começo da carreira de Gabriel Gregorio, com um objetivo: deixar quem nunca programou escrever o primeiro programa com as palavras que já usa no dia a dia. A primeira versão era uma linguagem e uma IDE feitas em Python, instaladas no computador, em português, inglês e espanhol.

A versão 0.38, de maio de 2021, foi a última em Python. Em 2026 a Safira foi reescrita do zero para a web, em TypeScript: a versão 1.0.0 levou a IDE para o navegador e para o celular, trouxe chinês e japonês, projetos com pastas, pontos de parada, inspetor de variáveis e as aulas com o gato. Agora a primeira linha de código está a um link de distância.

Antes de o código em Python sair do projeto, a saída dos programas foi gravada, e essa gravação virou um teste que roda até hoje: os scripts feitos para a versão em Python rodam igual na web.
