Safira について

Safira は日本語で書けるプログラミング言語で、プログラミングをしたことがない人のために作られました。英語、ポルトガル語、スペイン語、中国語にも対応していて、同じプログラムの中で言語を混ぜることもできます。ブラウザでそのまま動き、パソコンでもスマホでも使えます。インストールも登録も不要で、広告もありません。

誰のためのもの

  • 年齢を問わず、はじめてコードを書く人。
  • 何もインストールせずに、論理の最初の授業をしたい先生。
  • 英語が読めない人：Safira は日本語のほか、英語、ポルトガル語、スペイン語、中国語も話します。

短いプログラム

文字を表示するいろいろな書き方、同じ行への表示、2 つの言語の混在、くり返し、条件：

# 同じことを、いろいろな言い方で。色も付けられます。
名前 は "さくら"
年齢 は 12
表示 "こんにちは、" + 名前 + "！" 色 青
出力 "あなたは " + 年齢 + " 歳です。"
表示 "どれも文字を表示します。" 色 緑

# 同じ行に、英語でも。
続けて表示 "Safira は"
print "英語も"
show "話せます。"

繰り返す 3 回 {
    続けて表示 "⭐" 色 黄色い
}
表示 ""

もし 年齢 以上 10 なら {
    表示 "もうプログラミングできます! 🎉" 色 ピンク
} そうでなければ {
    表示 "手伝ってもらえばできます! 🎉"
}

表示される結果

こんにちは、さくら！
あなたは 12 歳です。
どれも文字を表示します。
Safira は英語も話せます。
⭐⭐⭐
もうプログラミングできます! 🎉

よくある質問

無料ですか？
はい。Safira はオープンソースで、MIT ライセンスです。
広告はありますか？
いいえ。広告はなく、操作を追跡するものもありません。
Safira を改造したり、自分のバージョンを作ったりできますか？
はい。ソースコードは GitHub にあり、MIT ライセンスです。ライセンス表示を残せば、コピーして改造し、自分のバージョンを公開できます。
インストールやアカウント登録は必要ですか？
いいえ。新しめのブラウザでサイトを開くだけです。アカウントはありません。
スマホで使えますか？
はい。スマホでは IDE がコード、出力、変数のパネルに分かれます。
コードはサーバーに送られますか？
いいえ。プログラムはブラウザで動き、プロジェクトはこのブラウザに保存されます。.zip で書き出せば、コピーを残したり別の端末に移したりできます。
同じプログラムで言語を混ぜられますか？
はい。すべての言語がいつでも有効で、同じ行でも混ぜられます。
ゲームは作れますか？
はい。プログラムはキーボードを読めます。「サンプル」メニューの恐竜やミニ RPG を開いてみてください。

歴史

Safira は 2019 年 8 月、Gabriel Gregorio のキャリアの初期に生まれました。目標はひとつ、プログラミングをしたことがない人が、ふだん使っている言葉で最初のプログラムを書けるようにすることです。最初のバージョンは Python で作られ、パソコンにインストールする言語と IDE で、ポルトガル語、英語、スペイン語に対応していました。

2021 年 5 月の 0.38 が最後の Python 版です。2026 年、Safira は TypeScript でウェブ向けに一から書き直されました。バージョン 1.0.0 で IDE がブラウザとスマホに移り、中国語と日本語、フォルダ付きのプロジェクト、ブレークポイント、変数インスペクター、猫と学ぶレッスンが加わりました。今ではリンクひとつで最初の一行が書けます。

Python のコードがプロジェクトから外れる前に、プログラムの出力がすべて記録され、その記録は今も動くテストになりました。Python 版のために書いたスクリプトは、ウェブでも同じように動きます。
