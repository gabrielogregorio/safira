关于 Safira

Safira 是一门可以用中文书写的编程语言，专为从没写过代码的人设计。它同样支持英语、葡萄牙语、西班牙语和日语，同一个程序里还能混用多种语言。程序直接在浏览器里运行，电脑和手机都可以：无需安装，无需注册，没有广告。

适合谁

  • 任何年龄、准备写下第一行代码的人。
  • 想在不安装任何软件的情况下上第一堂逻辑课的老师。
  • 不懂英语的人：Safira 会说中文，也会说英语、葡萄牙语、西班牙语和日语。

一个小程序

多种显示文字的写法、同一行输出、混用两种语言、一次重复和一个条件：

# 同一件事，有很多种说法，还能加颜色。
名字 设为 "小明"
年龄 赋值 12
显示 "你好，" + 名字 + "！" 颜色 蓝色
打印 "你今年 " + 年龄 + " 岁。"
输出 "这些都能显示文字。" 颜色 绿色

# 写在同一行，甚至可以用英语。
同行显示 "Safira "
同行打印 "也会说"
show "英语。"

重复 3 次 {
    同行显示 "⭐" 颜色 黄色
}
显示 ""

如果 年龄 大于等于 10 那么 {
    显示 "你已经可以编程了！🎉" 颜色 粉色
} 否则 {
    显示 "有人帮忙也可以！🎉"
}

运行结果

你好，小明！
你今年 12 岁。
这些都能显示文字。
Safira 也会说英语。
⭐⭐⭐
你已经可以编程了！🎉

常见问题

免费吗？
免费。Safira 是开源软件，采用 MIT 许可证。
有广告吗？
没有。没有广告，也不会追踪你的操作。
我可以修改 Safira 或做自己的版本吗？
可以。源代码在 GitHub 上，采用 MIT 许可证：你可以复制、修改并发布自己的版本，只需保留许可证声明。
需要安装软件或注册账号吗？
不需要。用较新的浏览器打开网站即可，没有账号系统。
手机上能用吗？
能。在手机上，IDE 会分成代码、输出和变量三个面板。
我的代码会上传到服务器吗？
不会。程序在浏览器中运行，项目保存在当前浏览器里。把项目导出为 .zip，就能保留副本或换到其他设备。
同一个程序里能混用多种语言吗？
能。所有语言随时都有效，甚至可以写在同一行。
能做游戏吗？
能。程序可以读取键盘。在「示例」菜单中打开恐龙或迷你 RPG 看看。

历史

Safira 诞生于 2019 年 8 月，那时 Gabriel Gregorio 刚开始职业生涯。它的目标只有一个：让从没写过代码的人，用日常说话的词语写出第一个程序。第一个版本是用 Python 编写、安装在电脑上的语言和 IDE，支持葡萄牙语、英语和西班牙语。

2021 年 5 月发布的 0.38 是最后一个 Python 版本。2026 年，Safira 用 TypeScript 为网页从头重写：1.0.0 版本把 IDE 带进了浏览器和手机，新增了中文和日语、带文件夹的项目、断点、变量查看器，以及由小猫带领的课程。现在，打开一个链接就能写下第一行代码。

在 Python 代码移出项目之前，所有程序的输出都被记录了下来，这份记录变成了一项至今仍在运行的测试：为 Python 版本写的脚本，在网页版上运行结果完全一样。
